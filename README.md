# ATENEA GAMES · NEON BOY SPACE-TIME 🚀

**Alpha 0.1** · Interactive HTML5 physics playground with a crimson metallic console, deep black display, neon effects and Web Audio sound.

## Play

Once GitHub Pages is enabled for **main / (root)**, open:

https://672gghgvzj-ship-it.github.io/neon-boy-space-time/

On iPhone, open the HTTPS address in Safari. The ChatGPT file preview may render HTML statically and cannot run the game.

## Modes

- **Particle Lab**: draw and snap figures, particle duplication, gravity points, black holes, wormholes, 2D and 3D projection, neon lighting.
- **LAUNCH SHIP / SPACE-TIME**: place fixed planets, a star or an idealized black hole; draw an intended direction and launch a spacecraft; pause/reset; optional thrusters; crew and reference clocks; synthetic sound effects enabled by a tap.

## Physics limits

The space trajectory uses a Newtonian test particle and simplified numerical integration; relativistic time factors are approximate demonstrations only, not a general relativity spacetime geodesic model. Time measured at the reference is a distant observer in the current approximation, not precisely a person on Earth's surface. Time and distance scaling are educational and may be artistically exaggerated.

## Enable GitHub Pages

1. Open the repo in your mobile browser (Safari) and use **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Choose branch **main**, folder **/(root)**, and **Save**.
4. After publication, open the game URL above.

No remote libraries or game analytics are embedded in the HTML; the code runs in the browser. The repository and its code are public.
